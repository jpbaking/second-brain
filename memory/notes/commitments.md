# Commitments

The follow-through ledger — different from reminders (self-contained
tasks): these are promises **between people**. Completed items get checked
and moved to Done (keep the history). Format:
`- [ ] YYYY-MM-DD due: what (to/from whom, agreed YYYY-MM-DD, source: [page](…))`
