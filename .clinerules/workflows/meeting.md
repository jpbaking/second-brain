# Workflow: file meeting minutes

The principal is giving you a meeting to record — as pasted notes, a file
in the inbox, or a verbal recap.

Steps:

1. If it's a file, first handle the original per the inbox workflow
   (library + catalog). The memory page below then links to it.
2. Create `memory/meetings/YYYY/YYYY-MM-DD_topic-slug.md` from
   `memory/meetings/_template.md`: attendees, agenda/context, discussion
   summary, **decisions**, **action items** (owner + due date), open
   questions.
3. Fan out the consequences:
   - Action items owned by the principal → `memory/notes/reminders.md`.
   - Facts about attendees (commitments, accomplishments, concerns) →
     their dossiers in `memory/people/`.
   - Project decisions/status → the project page in `memory/projects/`.
   Each fan-out entry links back to the meeting page.
4. Update `memory/meetings/index.md` and `memory/index.md`; append a
   `meeting` entry to `memory/log.md`.
5. Reply with the decisions and action items list, plus where it was filed.
