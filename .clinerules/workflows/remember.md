# Workflow: remember (chat capture)

The principal has just told you something worth keeping, or invoked this
with new information in the same message. File it.

Steps:

1. Identify the discrete facts in what was said. One message may carry
   several (a person fact + a reminder + a project update).
2. For each fact, find its home via the indexes: existing person dossier,
   project page, meeting file, `notes/reminders.md`, etc. Create pages from
   `_template.md` files only when no home exists.
3. Write dated entries (convert relative dates to absolute). For people
   facts, follow the special-care rules in `.clinerules/20-capture.md`.
4. Update indexes; append a `chat-capture` entry to `memory/log.md`.
5. Confirm in one or two lines: what was filed, where. If something was
   ambiguous (which "Alex"? which project?), file your best guess, mark it
   `⚠ unconfirmed`, and ask.
