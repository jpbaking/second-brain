# Workflow: recall (answer from the vault)

Answer the principal's question strictly per the retrieval rules
(`.clinerules/30-retrieval.md`).

Steps:

1. Parse the question; list the entities involved (people, projects,
   topics, time ranges).
2. Search: `memory/index.md` → candidate pages → read them → follow links
   one hop → grep `memory/` if thin → check `library/catalog.md` for
   under-extracted originals.
3. Answer: lead with the answer, cite source pages, separate recorded fact
   from inference, date time-sensitive facts, flag staleness and conflicts.
4. If the vault can't answer, say exactly what's missing and where you
   looked — then offer clearly-labeled general knowledge if useful.
5. If the synthesis was substantial, offer to save it as a memory page or
   report.
