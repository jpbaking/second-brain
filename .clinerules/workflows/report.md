# Workflow: report

Produce a report per `.clinerules/40-reports.md`.

Steps:

1. Clarify only what's essential and unstated: subject and format
   (markdown/HTML) if not inferable. Everything else, decide and note
   your assumptions in the reply.
2. Check `reports/templates/` for a matching template. If one exists,
   follow it exactly. If not, design a sensible structure — it becomes a
   template candidate the moment the principal gives feedback.
3. Gather content per the retrieval rules; the report's claims must trace
   to memory pages (include a discreet Sources section or footnotes).
4. Write to `reports/YYYY/YYYY-MM-DD_slug.md|.html`. Log it.
5. Reply with the path + 2–4 line executive summary + any data gaps that
   weakened the report ("no entries for X since May").
6. If feedback follows, apply it AND persist it to the template
   (create/update in `reports/templates/`), and say so.
