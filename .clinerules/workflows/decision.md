# Workflow: decision (record a decision)

The principal made, is making, or is weighing a significant decision —
technical, organisational, or professional. Get it on the record.

Steps:

1. Create `memory/decisions/YYYY-MM-DD_decision-slug.md` from
   `memory/decisions/_template.md` (date = decision date; status
   `proposed` if still open).
2. Capture context, the options **including the rejected ones and why**
   (that's the part future-them needs), the decision, and consequences.
   If the principal is still weighing it, fill Context/Options and stop
   at status `proposed` — offer a structured pros/cons pass.
3. Fan out: follow-up actions → `notes/commitments.md` or `reminders.md`
   with owners and dates; link the decision from the related project/
   people/meeting pages; set a `revisit by` date if the decision has an
   expiry condition.
4. If this supersedes an earlier decision page, mark that one
   `superseded by` with a link — never rewrite its history.
5. Update `memory/decisions/index.md` + master index count; log it.
6. Confirm in chat with the decision in one sentence and the follow-ups.
